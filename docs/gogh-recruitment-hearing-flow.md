# 採用ヒアリング項目（実施順）— 株式会社Gogh 伊藤様 業務メモ

- 対象: ある会社様の採用支援案件
- 目的: ここまでのやり取りを時系列で振り返り、実際に進んだヒアリングの順番を項目出ししたもの
- 記録日: 2026-08-29

## ヒアリング項目（実施順）

1. 採用計画（時期・人数）：いつ、何名採用したいか
2. 繁忙期・閑散期の状況：繁忙期・閑散期の売上規模
3. 業界動向・実績：業界内の好調事例、過去の売上実績
4. 売上の中長期見通し：来年・再来年の売上見込み
5. 決算・業績状況：決算期、今期業績、直近の実績人数と売上
6. 組織図の共有：社内体制・役職者の把握
7. 来季の採用計画・KPIの方向性：数値目標を立てる方針の確認
8. 採用の理想ペース：月あたり・四半期あたりの目標人数
9. 現場人材の現状：現場スタッフの参画経緯、自発性
10. 個別社員のパーソナリティ事例：未経験からの活躍事例（平工氏）
11. 社員の年齢層：平均年齢
12. 育成体制の現状：研修・オンボーディングの有無
13. 入社後の配属フロー：現場配属のタイミング
14. 他社の育成体制事例：マニュアル整備の有無（保母電設）
15. 市場環境（追い風要因）：ブルーカラー賃金上昇トレンド
16. 実施すべき施策：競合調査、給与相場調査、媒体運用方針
17. 採用ターゲットの属性：日本人／海外人材の可否
18. 必要資格・スキル要件：現場で求められる資格一覧
19. 一人前になるまでの年数：育成期間の目安
20. 事業内容の詳細：現場業務の具体的内容（重量飛び、機工設置）
21. 未経験者採用の方針：人柄・やる気重視のスタンス
22. 選考基準（定性面）：人物評価の観点
23. 競合他社の把握：岐阜エリアの同業他社
24. ベンチマーク企業：目指したい会社
25. 自社SNS・HP運用状況：Instagram・公式サイトの有無
26. KPI（獲得単価）：問い合わせ1件あたりのコスト目標
27. 採用オペレーション（役割分担）：Gogh対応か内製化か
28. 面接体制：誰が面接するか、頻度・工数
29. 面接シートの必要性：質問項目設計の要否
30. 他事業での採用実績事例：BAR事業の母集団形成の教訓

## Goghでの繋がっていきたい自社採用の定義

1. 第一印象（身なりを含む）
2. 話していて気持ちいいか
3. コミュニケーション力（立ち回り・素直さを含む）
4. 論理的思考力（受け答えを含む）

（上記「22. 選考基準（定性面）：人物評価の観点」に対応する、Gogh自社としての判断基準）
