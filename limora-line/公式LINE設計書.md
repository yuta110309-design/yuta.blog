# LIMORA 公式LINE 設計書

version 1.0 / 2026年9月

---

## 1. ゴール

公式LINEを通じて

1. **お客様(女性ユーザー)の満足度を上げる**
2. **会員登録への誘導を増やす**
3. **男性ユーザー(キャスト)の獲得を増やす**

の3つを同時に実現する。

サービス概要:LIMORAは「女性が選ぶ側になる新感覚・共感型オンライン交流プラットフォーム」。会員制で、キャストは審査を通過した男性のみ。

## 2. 想定ユーザーとタグ設計

| ユーザー種別 | 主な目的 | 発信チャネル |
| --- | --- | --- |
| 女性ユーザー(お客様) | LIMORAで気の合う相手と交流する | Instagram + 公式LINE(このリッチメニュー) |
| 男性キャスト | LIMORAで働く(審査制・応募条件なし) | X(旧Twitter) + 公式LINE |

### タグ設計(L Step想定)

- 属性タグ:`女性ユーザー` / `男性キャスト`
- 進捗タグ:`未登録` → `登録済み`(女性)、`未応募` → `応募済み`(男性)
- 進捗タグが完了状態に変わったら、該当のステップ配信を自動停止し、定期配信のみに合流させる

## 4. ステップ配信(挨拶メッセージ以降)

未登録/未応募のユーザーに対してのみ配信し、登録・応募が完了したタグに変わった時点で自動停止する。

### 女性ユーザー(登録までの後押し)

| タイミング | 内容 |
| --- | --- |
| Day0(選択直後) | サービス紹介+安心材料(審査制)+Instagramカード+登録カード |
| Day0〜1後 | 未登録なら、利用の流れ・よくある質問で不安解消+登録カード再送 |
| Day2〜3後 | 利用イメージ・新規登録特典(3,000P・15分無料トーク)を訴求して後押し |
| Day4以降も未登録 | ステップ終了 → 定期配信へ合流 |

### 男性キャスト(応募までの後押し)

| タイミング | 内容 |
| --- | --- |
| Day0(選択直後) | サービス紹介+「応募条件なし・審査制」+応募カード+Xカード |
| Day0〜1後 | 未応募なら、働き方の魅力(自由度・スキマ時間活用)を訴求 |
| Day2〜3後 | Q&Aで不安解消(審査基準・収入面など)+応募カード再送 |
| Day4以降も未応募 | ステップ終了 → 定期配信へ合流 |

## 6. 満足度を上げるための継続施策

CVだけでなく「入ってよかった」と思ってもらうための仕組み。

- **定期配信(週1〜2回目安)**:キャンペーン情報だけでなく、LIMORAの使い方Tips・よくある質問も混ぜて発信し、安心感を継続的に提供する
- **簡易アンケート配信**:「LIMORAの使い心地はいかがですか?」等、月1回程度の簡単なアンケートでフィードバックを収集し、運用改善に活かす
- **お問い合わせ導線の常時表示**:リッチメニューやメッセージ内に「気になることがあれば、このトークにそのまま送ってください」という一文を定常的に添え、離脱を防ぐ
- **パーソナライズ配信**:誕生日・登録記念日などのタイミングでの特別メッセージ・特典配布

## 7. 男性ユーザー(キャスト)獲得をさらに増やす施策

- **紹介施策**:既存キャストが友人を紹介した場合にポイント/特典を付与する仕組み(要検討)
- **実績・体験談の発信**:キャストの活動事例やリアルな声をX・LINEで定期的に発信し、応募への心理的ハードルを下げる
- **「応募条件なし」の継続訴求**:ステップ配信・定期配信の両方で繰り返し伝え、応募のハードルの低さを浸透させる
