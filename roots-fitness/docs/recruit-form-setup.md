# 採用応募フォームの設定手順(Googleフォーム + Apps Script)

採用ページ(recruit.html)の「応募する(代官山店)」「応募する(軽井沢店)」ボタンは、ページ内の独自デザインフォーム(`#recruit-apply`)までスクロールします。送信すると、裏側でGoogleフォームに回答データを送信し、Google Apps Script が応募者への確認メール送信・運営への通知メール送信・Notionへの一覧登録を自動で行います。体験予約・サポーター申込フォームと全く同じ仕組みです。

以下の作業は一度だけ、Googleアカウントを持つ運営担当が行います。コード(HTML/CSS/JS)の修正は不要です。

## 1. Googleフォームを作成する

新しいGoogleフォームを作成し、以下の6項目を**この順番・この質問文**で作成してください(質問文はApps Scriptが参照するため、変更する場合は `apps-script/notionSync.gs` 内の `RECRUIT_Q_NAME` 等の定数も合わせて変更が必要です)。

| # | 質問文 | 種類 | 選択肢 / 検証 | 必須 |
|---|---|---|---|---|
| 1 | お名前 | 記述式 | - | ○ |
| 2 | メールアドレス | 記述式 | 回答の検証: メールアドレス | ○ |
| 3 | お電話番号 | 記述式 | - | ○ |
| 4 | 応募店舗 | ラジオボタン | `代官山` / `軽井沢`(**文言を完全一致**させる) | ○ |
| 5 | ご経験・資格 | 記述式(段落) | - | 任意 |
| 6 | 志望動機・自己PR | 記述式(段落) | - | 任意 |

「応募店舗」は、他のフォーム(体験予約フォームの「店舗選択」、サポーターフォームの「ご利用店舗」)と質問文を絶対に重複させないでください。Apps Script側でこの質問文をもとに「どのフォームからの送信か」を判定しているため、質問文が一致すると誤動作します。

## 2. entry ID(各項目の送信キー)を取得する

サイト側の独自フォームからGoogleフォームへ直接送信するために、各質問の `entry.XXXXXXXXX` というIDが必要です。

1. 作成したフォームを開き、右上の「⋮」→「事前入力したURLを取得」(見当たらない場合はフォーム編集画面自体の「⋮」→「フォームに事前入力する」)を選択
2. 各項目に適当なダミー値を入力して「リンクを取得」
3. 発行されたURLをコピーし、`entry.123456789=...&entry.987654321=...` のような部分を確認する
4. 各 `entry.数字` がどの質問に対応するかをURLの並び順(入力した順)から特定する

## 3. `data/recruit-form.json` を編集する

1. フォームの回答送信先URLは、フォーム右上「送信」→ リンクアイコンで表示されるURLの末尾を `/viewform` から `/formResponse` に変更したものです(例: `https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse`)。これを `actionUrl` に設定します。
2. 手順2で取得した entry ID を、`fields` 内の対応する項目にそれぞれ設定します。

```json
{
  "actionUrl": "https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse",
  "fields": {
    "name": "entry.111111111",
    "email": "entry.222222222",
    "phone": "entry.333333333",
    "store": "entry.444444444",
    "experience": "entry.555555555",
    "motivation": "entry.666666666"
  }
}
```

## 4. Apps Script を設置する

体験予約フォーム・サポーター申込フォームと同じスプレッドシート/Apps Scriptプロジェクトに統合する運用です(まだ作っていない場合は、いずれかのフォームの「回答」タブ→緑のスプレッドシートアイコンから作成済みのスプレッドシートを使い、このフォームの回答も「既存のスプレッドシートを選択」で同じシートに連携させてください)。

1. フォームの「回答」タブ → 緑のスプレッドシートアイコン →「既存のスプレッドシートを選択」で、体験予約・サポーターと同じスプレッドシートに回答を連携する
2. そのスプレッドシートを開き、「拡張機能」→「Apps Script」を開く
3. `apps-script/notionSync.gs` の最新内容(採用応募フォーム対応版)をすべて貼り付けて保存
   (`NOTION_TOKEN` が `REPLACE_ME_` のままの間は、Notionへの書き込みだけ失敗するが
   メール送信には影響しない)
4. `RECRUIT_ADMIN_NOTIFY_EMAILS` は運営向けの新規応募通知先として `yuta110309@gmail.com,kawashima@proudc-inc.com` を設定済み(カンマ区切りで複数宛先。変更する場合はここを編集する)
5. 左メニューの「トリガー」(時計アイコン)→「トリガーを追加」
   - 実行する関数: `onRecruitFormSubmit`
   - イベントのソース: `スプレッドシートから`
   - イベントの種類: `フォーム送信時`
6. 保存時にGoogleアカウントの権限承認ダイアログが出るので許可する

## 5. Notionに一覧として反映する(任意)

採用応募の一覧・選考ステータス管理をNotionで行いたい場合、Notionデータベース「採用応募管理」を作成済みです(体験予約・サポーターと同じ仕組み。列: 名前/店舗/メールアドレス/電話番号/経験・資格/志望動機/ステータス/備考)。

https://app.notion.com/p/a7c0ea8be2d1492180b67b8bd2b6c9f2

1. [Notionのインテグレーション作成ページ](https://www.notion.so/profile/integrations)で新しいインテグレーションを作成し、シークレット(`ntn_...`)を取得する(体験予約・サポーターで作った「Roots Supporter連携」を使い回してよい)
2. 上記のNotionデータベースを開き、右上「•••」→「コネクト」→ 作成(または既存)のインテグレーションを選択して連携を許可する
3. `apps-script/notionSync.gs` 内の `NOTION_TOKEN` を手順1のシークレットに差し替えて保存(`RECRUIT_NOTION_DATABASE_ID` は設定済み)

## 6. 動作確認

1. 採用ページの「応募する(代官山店)」「応募する(軽井沢店)」それぞれから自分のメールアドレスでテスト送信
2. Googleフォームの回答スプレッドシートに行が追加されることを確認
3. 入力したメールアドレスに確認メールが届くことを確認
4. 運営通知メール(`RECRUIT_ADMIN_NOTIFY_EMAILS`)が届くことを確認
5. Notion連携も設定した場合は、上記のNotionデータベースにも同じ内容の行が追加されることを確認

## 補足

- サイト側の送信は `fetch(..., { mode: "no-cors" })` を使用しているため、送信の成功可否をブラウザ側で厳密には判定できません(Googleフォーム側の仕様上の制約)。送信ボタンを押すと基本的に「送信しました」表示になります。実際に回答が届いているかは上記「6. 動作確認」で確認してください。
- `data/recruit-form.json` が未設定(`REPLACE_ME_` のまま)の間は、実際の送信は行われず、ブラウザのコンソールに警告が出るのみです。UIの見た目・動作は確認できます。
- 同じスプレッドシート・Apps Scriptプロジェクトに複数フォームを紐づけているため、いずれかのフォームが送信されると全フォームのトリガー関数(`onFormSubmit` / `onSupporterFormSubmit` / `onRecruitFormSubmit`)が呼ばれます。各関数の先頭でそのフォーム固有の設問の有無をチェックして、他フォームの送信では何もしないようにしているため、通常は意識する必要はありません。
