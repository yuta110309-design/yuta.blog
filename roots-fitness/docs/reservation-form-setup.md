# 体験予約フォームの設定手順(Googleフォーム + Apps Script)

サイト上の「体験予約はこちら」ボタンは、ページ内モーダルの独自デザインフォームを開きます。送信すると、裏側でGoogleフォームに回答データを送信し、Google Apps Script が店舗ごとに異なる内容の確認メール(FitKarteの予約URLなど)を自動返信します。

以下の作業は一度だけ、Googleアカウントを持つ運営担当が行います。コード(HTML/CSS/JS)の修正は不要です。

## 1. Googleフォームを作成する

新しいGoogleフォームを作成し、以下の6項目を**この順番・この質問文**で作成してください(質問文はApps Scriptが参照するため、変更する場合は `apps-script/onFormSubmit.gs` 内の `Q_NAME` 等の定数も合わせて変更が必要です)。

| # | 質問文 | 種類 | 選択肢 / 検証 | 必須 |
|---|---|---|---|---|
| 1 | お名前 | 記述式 | - | ○ |
| 2 | ご年齢 | 記述式 | 回答の検証: 数値・10〜99の範囲 | ○ |
| 3 | 店舗選択 | ラジオボタン | `代官山` / `軽井沢`(**文言を完全一致**させる) | ○ |
| 4 | メールアドレス | 記述式 | 回答の検証: メールアドレス | ○ |
| 5 | お電話番号 | 記述式 | - | ○ |
| 6 | 知ったキッカケ | プルダウン | `Instagram` / `Google検索` / `ご紹介` / `その他` | 任意 |

店舗が増えた場合は、選択肢3に店舗を追加し、`apps-script/onFormSubmit.gs` の `STORE_REPLY_TEMPLATES` に同名のキーを追加してください。

## 2. entry ID(各項目の送信キー)を取得する

サイト側の独自フォームからGoogleフォームへ直接送信するために、各質問の `entry.XXXXXXXXX` というIDが必要です。

1. 作成したフォームを開き、右上の「⋮」→「事前入力したURLを取得」を選択
2. 各項目に適当なダミー値を入力して「リンクを取得」
3. 発行されたURLをコピーし、`entry.123456789=...&entry.987654321=...` のような部分を確認する
4. 各 `entry.数字` がどの質問に対応するかをURLの並び順(入力した順)から特定する

## 3. `data/reservation-form.json` を編集する

1. フォームの回答送信先URLは、フォーム右上「送信」→ リンクアイコンで表示されるURLの末尾を `/viewform` から `/formResponse` に変更したものです(例: `https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse`)。これを `actionUrl` に設定します。
2. 手順2で取得した entry ID を、`fields` 内の対応する項目にそれぞれ設定します。

```json
{
  "actionUrl": "https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse",
  "fields": {
    "name": "entry.111111111",
    "age": "entry.222222222",
    "store": "entry.333333333",
    "email": "entry.444444444",
    "phone": "entry.555555555",
    "source": "entry.666666666"
  }
}
```

## 4. Apps Script を設置する

1. フォームの「回答」タブ → 緑のスプレッドシートアイコンから、回答を記録するGoogleスプレッドシートを作成(まだ無ければ)
2. そのスプレッドシートを開き、「拡張機能」→「Apps Script」を開く
3. `apps-script/onFormSubmit.gs` の内容をすべて貼り付けて保存
   (`NOTION_TOKEN` が `REPLACE_ME_` のままの間は、Notionへの書き込みだけ失敗するが
   メール送信には影響しない。Notion連携を使う場合は下記「5. Notionに一覧として反映する」を参照)
4. `ADMIN_NOTIFY_EMAILS` は運営向けの新規予約通知先として `yuta110309@gmail.com,kawashima@proudc-inc.com` を設定済み(カンマ区切りで複数宛先。宛先を変更・追加する場合はここを編集する)
5. 軽井沢店のFitKarte予約URLが確定したら `STORE_REPLY_TEMPLATES["軽井沢"].fitkarteUrl` を差し替える
6. 左メニューの「トリガー」(時計アイコン)→「トリガーを追加」
   - 実行する関数: `onFormSubmit`
   - イベントのソース: `フォームから`
   - イベントの種類: `フォーム送信時`
7. 保存時にGoogleアカウントの権限承認ダイアログが出るので許可する

## 5. Notionに一覧として反映する(任意)

体験予約の一覧・ステータス管理をNotionで行いたい場合、Notionデータベース「体験予約管理」を作成済みです(サポーターフォームと同じ仕組み。列: 名前/年齢/店舗/メールアドレス/電話番号/知ったキッカケ/ステータス/申込日時/備考)。

https://app.notion.com/p/20ce7162893c461ea0b2696a22e17c87

1. [Notionのインテグレーション作成ページ](https://www.notion.so/profile/integrations)で新しいインテグレーションを作成し、シークレット(`ntn_...`)を取得する
   (サポーターフォームで作った「Roots Supporter連携」を使い回してもよい。その場合は次の手順で同じインテグレーションを接続する)
2. 上記のNotionデータベースを開き、右上「•••」→「コネクト」→ 作成(または既存)のインテグレーションを選択して連携を許可する
3. `apps-script/onFormSubmit.gs` 内の `NOTION_TOKEN` を手順1のシークレットに差し替えて保存(`NOTION_DATABASE_ID` は設定済み)

## 6. 動作確認

1. サイトの「体験予約はこちら」から自分のメールアドレスでテスト送信
2. Googleフォームの回答スプレッドシートに行が追加されることを確認
3. 入力したメールアドレスに、選択した店舗名の入った確認メールが届くことを確認
4. 代官山・軽井沢の両方でテストし、それぞれ正しい本文(FitKarte URL)が届くか確認
5. Notion連携も設定した場合は、上記のNotionデータベースにも同じ内容の行が追加されることを確認

## 補足

- サイト側の送信は `fetch(..., { mode: "no-cors" })` を使用しているため、送信の成功可否をブラウザ側で厳密には判定できません(Googleフォーム側の仕様上の制約)。送信ボタンを押すと基本的に「送信しました」表示になります。実際に回答が届いているかは上記「5. 動作確認」で確認してください。
- `data/reservation-form.json` が未設定(`REPLACE_ME_` のまま)の間は、実際の送信は行われず、ブラウザのコンソールに警告が出るのみです。UIの見た目・動作は確認できます。
