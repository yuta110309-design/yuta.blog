# オフィシャルサポーター制度 申込フォームの設定手順(Googleフォーム)

`supporter.html`(非公開ページ。ナビ等からはリンクしておらず、URLを直接お伝えした方のみ閲覧できます)の申込フォームは、体験予約フォームと同じ仕組みです。送信すると、裏側でGoogleフォームに回答データを送信します。

以下の作業は一度だけ、Googleアカウントを持つ運営担当が行います。コード(HTML/CSS/JS)の修正は不要です。

## 1. Googleフォームを作成する

新しいGoogleフォームを作成し、以下の6項目を作成してください(質問文・順番は自由です。次の手順でentry IDを取得して対応付けます)。

| # | 質問文(例) | 種類 | 選択肢 / 検証 | 必須 |
|---|---|---|---|---|
| 1 | お名前 | 記述式 | - | ○ |
| 2 | お電話番号 | 記述式 | - | ○ |
| 3 | メールアドレス | 記述式 | 回答の検証: メールアドレス | ○ |
| 4 | ご利用店舗 | ラジオボタン | `代官山` / `軽井沢`(**文言を完全一致**させる) | ○ |
| 5 | Instagramアカウント | 記述式 | - | ○ |
| 6 | 同意確認 | 記述式(またはチェックボックス) | - | ○ |

## 2. entry ID(各項目の送信キー)を取得する

1. 作成したフォームを開き、右上の「⋮」→「事前入力したURLを取得」を選択
2. 各項目に適当なダミー値を入力して「リンクを取得」
3. 発行されたURLをコピーし、`entry.123456789=...&entry.987654321=...` のような部分を確認する
4. 各 `entry.数字` がどの質問に対応するかをURLの並び順(入力した順)から特定する

## 3. `data/supporter-form.json` を編集する

1. フォームの回答送信先URLは、フォーム右上「送信」→ リンクアイコンで表示されるURLの末尾を `/viewform` から `/formResponse` に変更したものです。これを `actionUrl` に設定します。
2. 手順2で取得した entry ID を、`fields` 内の対応する項目にそれぞれ設定します。

```json
{
  "actionUrl": "https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse",
  "fields": {
    "name": "entry.111111111",
    "phone": "entry.222222222",
    "email": "entry.333333333",
    "store": "entry.444444444",
    "instagram": "entry.555555555",
    "agree": "entry.666666666"
  }
}
```

## 4. 回答の管理先(Notion)

申込内容を管理するNotionデータベース「オフィシャルサポーター制度 申込管理」を作成済みです(現時点では自分だけが見られる非公開ページ。共有したい場所が決まったら教えてください、そちらに移動します)。

https://app.notion.com/p/04298fd2ad344f9cb2f6e4a934ee44d0

列: 名前 / 電話番号 / メールアドレス / 利用店舗 / Instagram / ステータス(未対応・連絡済み・説明会調整中・確定・見送り)/ 申込日時 / 備考

Googleフォームの回答をこのデータベースに**自動転記**するため、`apps-script/onSupporterFormSubmit.gs` を用意しています。設置方法はファイル冒頭のコメントに記載していますが、大まかな流れは次のとおりです。

1. [Notionのインテグレーション作成ページ](https://www.notion.so/profile/integrations)で新しいインテグレーションを作成し、シークレット(`ntn_...`)を取得する
2. 上記のNotionデータベースを開き、右上「•••」→「コネクト」→ 作成したインテグレーションを選択して連携を許可する
3. `apps-script/onSupporterFormSubmit.gs` の内容を、Googleフォームの回答スプレッドシート(または フォーム編集画面右上「⋮」)から「拡張機能 > Apps Script」を開いて貼り付け、`NOTION_TOKEN` を手順1のシークレットに差し替えて保存
4. 左メニュー「トリガー」から `onSupporterFormSubmit` を追加(イベントのソース: フォームから / イベントの種類: フォーム送信時)
5. 初回保存時にGoogleアカウントの権限承認を求められるので許可する

## 5. 動作確認

1. `supporter.html` を開き、自分の情報でテスト送信
2. Googleフォームの回答スプレッドシート(「回答」タブ→緑のスプレッドシートアイコン)に行が追加されることを確認
3. Notion連携も設定した場合は、上記のNotionデータベースにも同じ内容の行が追加されることを確認

## 補足

- サイト側の送信は `fetch(..., { mode: "no-cors" })` を使用しているため、送信の成功可否をブラウザ側で厳密には判定できません。送信ボタンを押すと基本的に「送信しました」表示になります。実際に回答が届いているかは上記「5. 動作確認」で確認してください。
- `data/supporter-form.json` が未設定(`REPLACE_ME_` のまま)の間は、実際の送信は行われず、ブラウザのコンソールに警告が出るのみです。UIの見た目・動作は確認できます。
- 体験予約フォームのように自動返信メールも必要な場合は、`docs/reservation-form-setup.md` の「4. Apps Scriptを設置する」を参考に、同様のスクリプトを追加できます(現状は未設定。Notion連携用のスクリプトと共存できます)。
